Guide & API

Install Snekweb, register routes and middleware, and connect it to Node.js.

Installation

Requires Node.js 20 or newer. Install from npm:

npm install snekweb

Your first app

import { Snek } from 'snekweb'

const app = new Snek()

app.get('/', (c) => c.text('Hello, world!'))
app.get('/users/:id', (c) => c.json({ id: c.req.param('id') }))

await app.listen(3000)

Use fetch(Request) when integrating with another server or testing without opening a socket. listen(port, { host }) starts the built-in Node.js HTTP adapter.

Routing

Register routes with get, post, put, patch, delete, options, head, all, or on(method, path, ...handlers). The generic method accepts methods without a dedicated helper, including CONNECT, TRACE, and QUERY; the exported METHODS constant lists the built-in HTTP methods. Paths support named :param segments and * wildcards. HEAD falls back to a matching GET route and suppresses the response body.

app.get('/users/:id', (c) => c.json({ id: c.req.param('id') }))

app.group('/api', (api) => {
  api.get('/health', (c) => c.json({ ok: true }))
  api.get('/users/:id', (c) => c.json({ id: c.req.param('id') }))
})

Unknown paths use the default 404 response. A known path with an unsupported method returns 405 and an Allow header; unhandled OPTIONS requests receive 204 with the allowed methods. Register an explicit OPTIONS route to customize it.

Middleware and errors

Middleware runs in registration order and receives (context, next). It can run logic before and after downstream handlers. Path-scoped middleware matches that path and its descendants, not similarly prefixed sibling paths.

app.use(async (c, next) => {
  const started = Date.now()
  await next()
  console.log(c.req.url.pathname, Date.now() - started)
})

app.use('/api', async (c, next) => {
  c.header('x-api', 'v1')
  await next()
})

Customize missing routes with notFound(handler) and errors with onError(handler). Handlers must return a Web API Response.

Request and response helpers

Read a request

c.req.param(name), query(name), queries(name), header(name), contentType(), cookie(name), json(), text(), formData(), and arrayBuffer().

Build a response

c.text(), html(), json(), redirect(), and body() return standard Web API Response objects.

Set headers and cookies

c.header(name, value), c.cookie(name, value, options), and c.deleteCookie(name, options) configure response headers and cookies.

app.post('/echo', async (c) => {
  const data = await c.req.json()
  return c.json({ received: data }, 201)
})

Static files

serveStatic(root) creates middleware for basic static-file serving. It supports MIME types, optional index files, conditional Last-Modified requests, and traversal/symlink containment checks. It serves GET and HEAD, falls through for missing files, and does not provide directory listings or range requests.

import { Snek, serveStatic } from 'snekweb'

const app = new Snek()
app.use('/assets', serveStatic('./public'))

Node.js integration

listen() uses Node.js node:http for socket handling and HTTP parsing, adapts requests to Fetch API objects, and streams responses with backpressure. The optional C++ N-API addon is only a capability probe: it is not loaded for normal use and does not handle requests. Snekweb does not bind OS sockets directly.

All exported API declarations are included for TypeScript users. Application-level middleware can provide policies such as authentication, validation, rate limiting, or CORS.
